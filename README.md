Projeto desenvolvido para o **Checkpoint 1** da disciplina de Web Development da FIAP, com o objetivo de praticar conceitos fundamentais de programação utilizando JavaScript.

## Sobre o projeto

O projeto consiste na resolução de 10 exercícios de lógica de programação em JavaScript, abordando operadores, estruturas condicionais, estruturas de repetição, arrays, variáveis e manipulação de dados.

As soluções foram desenvolvidas para apresentar seus resultados no console do navegador, permitindo acompanhar a execução e compreender o funcionamento de cada exercício.

## Exercícios

| Nº | Descrição |
|---|---|
| 01 | Demonstração dos operadores `!=`, `===` e `>=`. |
| 02 | Cálculo do Índice de Massa Corporal (IMC) utilizando `if/else` encadeado. |
| 03 | Estrutura de repetição `for` com contagem até 10. |
| 04 | Listagem de elementos de um array de personagens. |
| 05 | Verificação de permissão utilizando operador ternário. |
| 06 | Validação de login com usuário e senha predefinidos. |
| 07 | Cálculo da média de sete notas e verificação de aprovação. |
| 08 | Exibição de mensagem personalizada utilizando template strings. |
| 09 | Validação de alteração de senha, impedindo a reutilização da senha atual. |
| 10 | Cálculo do valor final de um produto após aplicação de desconto. |

## Tecnologias utilizadas

- **HTML5:** Estrutura da página.
- **JavaScript:** Desenvolvimento da lógica dos exercícios.
- **Git:** Versionamento do código.
- **GitHub:** Hospedagem do repositório.
- **Visual Studio Code:** Ambiente de desenvolvimento.

## Como executar

1. Clone o repositório ou faça o download dos arquivos.
2. Abra o projeto no Visual Studio Code.
3. Execute o arquivo `index.html` em um navegador.
4. Abra as ferramentas de desenvolvedor pressionando `F12`.
5. Acesse a aba **Console** para visualizar os resultados dos exercícios.

## Objetivo acadêmico

Aplicar os conhecimentos adquiridos durante as aulas de Web Development, desenvolvendo a capacidade de interpretar problemas, construir soluções utilizando JavaScript e compreender os resultados apresentados no console.

O projeto também busca reforçar boas práticas de organização de arquivos e versionamento de código com Git.
